# ИНСОМНИЯ — хоррор-квест в Караганде

Промо-сайт хоррор-квеста «Инсомния» (ул. Новосёлов, 145/1, Караганда).

Next.js 15 · React 19 · Tailwind CSS 4 · TypeScript

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

## Команды

```bash
npm run build      # продакшн-сборка
npm run start      # запуск сборки
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
```

## Структура

```
src/
  app/
    page.tsx              главная: hero, trust, квесты, процесс, отзывы, FAQ, карта
    booking/              бронирование: 3 шага + success
    quests/[slug]/        страница квеста
    api/booking/          приём заявок (валидация, понятные ошибки)
    globals.css           дизайн-система
  components/             Header, Intro, SoundToggle, StickyCta, секции
  data/business.ts        ЕДИНЫЙ ИСТОЧНИК ПРАВДЫ по бизнесу
  lib/bookings.ts         хранилище заявок
```

## Важно про данные

**Не выдумываются** цены, количество игроков, длительность, возрастные
ограничения и тексты отзывов: 2ГИС отдаёт их только после прохождения
антибот-защиты. В `src/data/business.ts` эти поля равны `null`, на сайте
показывается прочерк и отсылка к администратору.

Подтверждённые данные и список того, что нужно от клиента, — в
[RESEARCH.md](./RESEARCH.md).

## Перед запуском в бой

1. Цены и тарифы.
2. Игроки / длительность / возраст по каждому квесту.
3. Реальные фотографии локаций + разрешение на использование фото 2ГИС/Instagram.
4. Куда отправлять заявки (сейчас пишутся в `data/bookings.json`).
