# ИНСОМНИЯ — хоррор-квест в Караганде

Промо-сайт хоррор-квеста «Инсомния» (ул. Новосёлов, 145/1, Караганда).

Next.js 15 · React 19 · Tailwind CSS 4 · TypeScript

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

## Команды

```bash
npm run build      # продакшн-сборка
npm run start      # запуск сборки
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
```

## Структура

```
src/
  app/
    page.tsx              главная: hero, trust, квесты, процесс, отзывы, FAQ, карта
    booking/              бронирование: 3 шага + success
    quests/[slug]/        страница квеста
    api/booking/          приём заявок (валидация, понятные ошибки)
    globals.css           дизайн-система
  components/             Header, Intro, CctvPhoto, Flashlight, Watcher,
                          DotMatrix, CountUp, Sigil, Scare, секции
  data/business.ts        ЕДИНЫЙ ИСТОЧНИК ПРАВДЫ по бизнесу
  data/photos.ts          кадры галереи + авторство + источник
  lib/bookings.ts         хранилище заявок
public/
  photos/                 реальные кадры (1500 px, JPEG q80, EXIF срезан)
  og.jpg                  карточка для соцсетей, 1200×630
```

## Медиа

Кадры не «лежат в репозитории однажды»: `public/photos` — результат разовой
выгрузки галереи 2ГИС. Если у заведения появятся новые фото, порядок такой:

1. скачать исходники с CDN 2ГИС;
2. привести к ширине 1500 px, пережать в JPEG q80, **срезать EXIF** (в снимках
   гостей бывают геометки);
3. дописать запись в `src/data/photos.ts` с автором и датой.

`og.jpg` собирается из кадра локации с той же цветокоррекцией, что и на сайте,
поэтому превью в мессенджере не расходится с тем, что видит посетитель.

## Важно про данные

Все цифры и цитаты проходят через `src/data/business.ts`. **Не выдумываются**
количество игроков, длительность, возрастные ограничения и цена INSOMNIA
CINEMA: в публичных источниках их нет, поэтому в коде это `null`, а на сайте —
прочерк и отсылка к администратору.

Что заполнено и откуда:

- Цена «Забытых душ» — **от 4 000 ₸** из прайс-листа 2ГИС (обновлён 6 мая 2026).
- Оплата, парковка, ориентир и доп. услуги (антикафе, аренда комнаты) —
  вкладка «Инфо» 2ГИС.
- Блок отзывов показывает **8 реальных цитат** из вкладки «Отзывы» 2ГИС
  (`reviews` в `business.ts`), текст не редактировался, сокращения помечены
  многоточием. Агрегаты (5.0 / 205 оценок / 134 отзыва) берутся из карточки
  целиком, выборка цитат их не искажает.

Подтверждённые данные и список того, что нужно от клиента, — в
[RESEARCH.md](./RESEARCH.md). Разбор проблем сайта и что осталось на решение
владельца — в [AUDIT.md](./AUDIT.md).

## Перед запуском в бой

1. Игроки / длительность / возраст по каждому формату.
2. Цена INSOMNIA CINEMA (в прайсе 2ГИС её нет) и подтверждение актуальности
   «от 4 000 ₸».
3. Разрешение клиента на публикацию цитат из отзывов 2ГИС.
4. Реальные фотографии локаций + разрешение на использование фото 2ГИС/Instagram.
5. Куда отправлять заявки (сейчас пишутся в `data/bookings.json`).
